## Offline importer and regression reproduction

```sh
python3 tools/import_issue156_logs.py ORIGINAL.txt \
  --source-url CANONICAL_URL --published-at ISO_TIMESTAMP --output timeline.json
python3 tools/import_issue156_logs.py test/corpus/issue156_rs100_fixtures.json \
  --generate-header --output test/corpus/issue156_rs100_fixtures.h
python3 test/test_issue156_import.py
```

The importer never downloads/executes a target or modifies its input. It hashes
original bytes before decoding; strict contiguous offset checks reject duplicate,
out-of-order, missing or summary-inconsistent dump bytes. Completion is separate
from object semantics. Raw secret-bearing bodies are excluded before derivative
serialization. It does not infer absent observations or complete a truncated
message from surrounding context. Review selects frames from imported timelines;
that selection is explicit in the fixture JSON.

The unit test covers byte/provenance identity, distinct repeated observations,
private-body omission, parse failure/masking, metadata/declared-length mismatch,
complete/partial object bounds, duplicate/gap/out-of-order offsets, unknown-object
redaction, message-level retry retention, reproducible generated fixtures and the
bounded input size. Native corpus integration is separate from these import tests.
