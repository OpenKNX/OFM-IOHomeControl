# Produktwerte diagnostisch lesen

„Produktwerte abfragen“ fordert Rohdaten vom Aktor an. Eine ausdrücklich gewählte Produktdefinition legt deren Bedeutung fest; „Bedeutungen anzeigen“ erklärt die Felder und „diagnostisch dekodieren“ interpretiert einen vorhandenen Wert. Temperaturgrenzen nur aus bestätigten Produktinformationen eintragen. Diese Diagnoseauswahl schaltet weder Funk-Stellbefehle noch KNX-Rückmeldungen frei.
