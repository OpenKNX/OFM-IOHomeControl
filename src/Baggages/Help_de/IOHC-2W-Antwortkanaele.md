# 2W Antwortkanäle

„Kurzzeitige Kanaldiversität“ bevorzugt beim Wechsel eine andere, zuletzt nicht benutzte Funkfrequenz. Eine benutzte Frequenz wird nur kurz (standardmäßig etwa 250 ms) zurückgestellt und bleibt danach erreichbar. „Alle drei Kanäle“ durchsucht die Frequenzen ohne diese Bevorzugung. Die normale Hintergrundsuche berücksichtigt immer alle drei Kanäle.
