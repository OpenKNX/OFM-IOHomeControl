# Import-Kandidat

0 wählt alle unterstützten gefundenen Geräte; eine andere Nummer wählt nur diesen Kandidaten aus der Suchliste. Die Nummer ist keine Funkadresse. Vor der Übernahme die Zuordnungsvorschau prüfen.

Bei 0 werden Kandidaten ohne erkannte Metadaten oder ohne passendes Profil
übersprungen. Ein ausdrücklich gewählter, verifizierter Kandidat kann auch ohne
Metadaten zugeordnet werden; der Gerätetyp muss dann manuell gewählt werden.
