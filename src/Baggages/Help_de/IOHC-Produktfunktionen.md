# Produktfunktionen

Zusätzliche KNX-Objekte für Farbe, Farbtemperatur, Temperatur oder Betriebsmodus. Sichtbare Objekte bedeuten noch keine Geräteunterstützung: Senden und Rückmeldung bleiben bis zur bestätigten Produktzuordnung und Freigabe gesperrt. „Produktwerte gültig“ zeigt, ob nutzbare Werte vorliegen; eine Rohdatenabfrage allein erteilt keine Freigabe.
