# Sensor-Backbone

Explizite Kennung für das Sensorabonnement als genau sechs Hex-Ziffern, ungleich 000000. Sie bestimmt das Ziel bzw. den Bezug der Sensoranmeldung. Nur eine bekannte passende Kennung verwenden. Erst die Schaltfläche „Default-Sensorabonnement schreiben“ sendet die Änderung; dies erzeugt keine KNX-Sensorrückmeldung.
