# Sensoren und Prioritäten

2W-Werkzeuge zur Fehlersuche. „Sensorinformation“ liest Fähigkeiten, „Sensorstatus“ und „Priorität“ fragen Rohwerte an. Anschließend „Prioritäts- / Sensorevidenz lesen“. Die zeitlich begrenzte Rohwertabfrage läuft nach Intervall und Dauer. „Default-Sensorabonnement schreiben“ sendet eine Anmeldung an das ausdrücklich eingetragene Backbone; Geräteakzeptanz danach prüfen. Keine automatische KNX-Sensorrückmeldung.
