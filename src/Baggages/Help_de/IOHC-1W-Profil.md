# 1W Controllerprofil

0 verwendet die eigene Fernbedienungsidentität des Kanals. Eine Kanalnummer verwendet das Profil eines anderen 1W-Kanals: Beide teilen Funkadresse, Schlüssel, Hersteller und den gespeicherten Befehlszähler. So können sie dieselbe angelernte Gruppe steuern. Ungültige oder zyklische Verweise verwenden das eigene Profil.

Nach einem Profilwechsel die betroffenen Aktoren erneut anlernen. „Neues eigenes 1W-Controllerprofil erzeugen“ erstellt eine neue zufällige Identität. Ein gepaart verwendetes Profil kann nicht ersetzt werden. Das Klonen einer Originalfernbedienung ist eine Expertenaktion und benötigt ein eigenes, unbenutztes Profil. 1W liefert keine bestätigte Aktorrückmeldung.
